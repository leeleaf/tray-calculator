# 托盘摆放计算器

这是一个轻量级前端工具，用于根据托盘尺寸、物品尺寸和单边最大超出量，自动计算最佳摆放方式，并在页面中生成托盘摆放示意图。

## 使用方式

1. 打开 `index.html` 文件。
2. 输入:
   - 托盘长度（mm）
   - 托盘宽度（mm）
   - 单边最大超出（mm）
   - 物品长度（mm）
   - 物品宽度（mm）
3. 点击“计算布局”。
4. 页面会自动显示推荐摆放方向和示意图。

## 示例参数

- 托盘：1200 × 1000 mm
- 单边最大超出：250 mm
- 物品：1320 × 550 mm

预设值已对应这组数据。

## 说明

- 计算器会自动比较两种摆放方向：
  - 长边方向：货物长边与托盘长边同向
  - 短边方向：货物长边与托盘宽边同向
- 结果中会显示超出量是否满足要求。
- 示例图中用蓝色表示托盘，橙色表示货物，浅色区域表示超出部分。
